# Docs

Working documents for the cannabis transport market analysis.

- [`market-analysis/`](market-analysis/) — the starter structural analysis (markdown source +
  styled viewer page).

## Add a new doc
1. Create `docs/<slug>/<slug>.md` and write in Markdown (GitHub-flavored).
2. Copy `market-analysis/index.html` to `docs/<slug>/index.html` and change the `fetch()` target to
   your `.md` filename. That gives you a styled, browsable page on the Pages site while keeping the
   markdown as the single source of truth.
3. Add a card to the **Docs** section of `../index.html`.

_This repo is public — keep confidential material out._
