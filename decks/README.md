# Decks

Presentation decks for the cannabis transport market analysis.

## Convention
- **Drop files here** — prefer **PDF** exports (render in-browser, portable). `.pptx` / `.key`
  source files are fine to keep alongside.
- Name files `YYYY-MM-DD-topic.pdf`, e.g. `2026-10-05-market-overview.pdf`.
- After adding a deck, add a linking card to the **Decks** section of `../index.html`
  (copy an existing card).

_Decks may contain client-confidential material — remember this repo is public. Keep anything
sensitive out of version control._
